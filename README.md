# Дом в Щучинске — галерея

Статическая галерея проекта: интерьер по комнатам, терраса и фасад, план этажа.
Без сборки и зависимостей — это обычный HTML, открывается двойным кликом.

## Что где

- `index.html` — готовая страница (её и открывает браузер)
- `template.html` — шаблон, список кадров подставляется в него
- `data.json` — комнаты, площади и имена файлов
- `img/` — полноразмерные кадры, открываются в лайтбоксе
- `thumb/` — превью для сетки, чтобы страница грузилась быстро
- `build.py` — пересобирает `index.html` из шаблона и `data.json`

## Как добавить или заменить кадр

1. Положить файл в `img/rooms/` (или `img/ext/`)
2. Вписать имя файла в нужную комнату в `data.json`
3. `python3 build.py --thumbs` — сделает превью и пересоберёт страницу

Деплой: любой статический хостинг, папка отдаётся как есть.
